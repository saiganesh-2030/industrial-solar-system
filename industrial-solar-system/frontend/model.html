Pipeline Feature Engineering and Hyperparameters

Input Feature Columns (in exact order):
  1. PLANT_ID: Categorical (4135001 or 4136001), OneHotEncoded.
  2. TIME_SIN: sin(2 * π * minutes / 1440) cyclic time feature.
  3. TIME_COS: cos(2 * π * minutes / 1440) cyclic time feature.
  4. AMBIENT_TEMPERATURE: Ambient outdoor temperature (°C).
  5. MODULE_TEMPERATURE: Back-of-panel PV temperature (°C).
  6. IRRADIATION: Solar irradiance (kW/m²).
Tuned Hyperparameters:
  • n_estimators: 200 trees
  • max_depth: None (unconstrained tree growth)
  • min_samples_split: 5 samples
  • min_samples_leaf: 2 samples
  • max_features: 1.0 (all features considered at split)
  • random_state: 42 (reproducible cross-validation)
